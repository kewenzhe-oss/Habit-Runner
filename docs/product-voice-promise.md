# 產品語氣：對自己的承諾

Habit Runner 把使用者選擇去做的事視為對自己的承諾。承諾有分量：寫下它，是決定認真對待自己的話，並以具體行動兌現。信任從對自己說過的話開始。

## 語氣原則

- 用第一人稱和清楚的行動，幫助使用者說出自己想做什麼；由使用者決定承諾，而非系統替他許諾。
- 鼓勵真誠和履行，不用羞恥、懲罰或道德評價推動行動。未做到時，提供記錄、調整和重新開始的空間。
- 休息與調整可以是負責任的選擇；不要暗示降低目標或休整等於失信。
- 文字具體、平實、有分量，少用口號、空泛激勵和誇張的比喻。
- 在入口和操作上保留易懂的「新增事項」「保存」等詞彙；承諾是體驗的含義，不應讓功能名稱變得難以辨認。

## 新增流程的起點

標題：「給自己一個承諾」；說明：「寫下你想認真做到的事。從一個具體、做得到的行動開始。」其餘頁面可按同一原則逐步調整，並根據實際使用情境檢查語氣。
